# Timespan

Timespan is an application that helps with tracking working time and allows
exporting it to a wekly report file in pdf format. 

The project is built with **Avalonia** and runs on **.NET 10**.  
Data is stored locally to keep the application simple and fast to use.

## Features

- Clean and structured desktop interface
- Focus on minimal required actions to track time
- Local data storage

## Technologies

- C#
- Avalonia
- Entity Framework Core
- SQLite

## Project Goal

The goal of Timespan is to provide a compact and modern application that
reduces the effort for tracking working time to as close to zero as possible.
